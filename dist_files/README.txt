Armoured Commander II 日本語化パッチ（非公式・有志）
====================================================

Steam 版 Armoured Commander II（v1.3.8 で確認）の画面を日本語で表示するパッチです。
ゲームの会社・作者とは関係のない非公式のものです。問い合わせは作者ではなく配布元へお願いします。


■ 入れ方
1. ZIP をすべて展開します（場所はどこでもかまいません）。
2. ゲームを終了した状態で「ArmCom2_JA.exe」をダブルクリックします。
   ゲームのフォルダは Steam の設定から自動で探します。見つからないときは入力を求められます。
3. 「完了しました」と出たらゲームを起動します。
4. ゲームのオプションで「フォントサイズ」を 16x16 にしてください（8x8 では漢字がつぶれます）。

Windows の警告（SmartScreen）が出たら「詳細情報」→「実行」を押してください。
「書き込めませんでした」と出たら、右クリック →「管理者として実行」で試してください。


■ 元に戻す
「元に戻す.cmd」をダブルクリックします。
Steam の「ゲームファイルの整合性を確認」でも元に戻ります（ja フォルダは残りますが無害です）。


■ ゲームが更新されたら
更新で exe が元に戻り、英語表示になります。もう一度「ArmCom2_JA.exe」を実行してください。


■ このパッチがすること
- armcom2.exe の起動部分だけを差し替え、ゲームのフォルダに作る ja フォルダの boot.py を読み込ませます。
  元の exe は armcom2.exe.jabak として残します。
- boot.py は、画面に文字を出す直前に英語を日本語に置き換えます。
  ゲームが付けているソース（src\armcom2.py）は書き換えず、起動のたびにメモリ上で日本語表示に必要な所（3か所）だけ直して動かします。
- 日本語の文字は、ゲームのフォント画像と、お使いの Windows の MS ゴシックから、その場で作ります（ja\font_NN.png）。
- ゲームのファイル・フォントの画像は、このパッチには入っていません。


■ 訳した範囲
画面の文言、用語集、スキル、チュートリアル、乗員の命令とセリフ・階級・勲章、
キャンペーン名・説明・週ごとの説明、車両名、兵器の解説。
型番だけの兵器名（wz. 28、PaK 38 など）と、文をつなぎ合わせて出すメッセージの一部は英語のままです。

訳し漏れの報告: 遊んでいる間、訳が無かった英語が
ゲームのフォルダの ja\missing.txt に書き出されます。これを送ってもらえると助かります。


■ おまけ
- survivor_guide.html: Steam ガイド「Survivalist's Guide to Armoured Commander 2」（flori2412 作）の日本語版。
  戦い方のコツと兵器の貫通力一覧。ブラウザで開いてください。著作権は著者にあります。
